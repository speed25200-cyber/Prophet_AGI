## Allocation warnings

- frontend/embeddings holds 155.58M params (35.5% of the model), above the 20% guideline — these parameters do no computation.
- attention inside the looped core (core[0], core[1], core[2], core[3], core[4], core[5], core[6], core[7], core[8], core[9]): its KV cache is duplicated per iteration, so memory scales with k (x2 at the default depth). This is decision D1's invariant; enable it only as the deliberate A-KV ablation.
- full-attention layers are present but nope_layers is empty: without a position-free global layer, length extrapolation has to be bought with a context-extension run instead of coming for free
